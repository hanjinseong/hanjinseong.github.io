Research 01

Multi-Agent based Parametric Motor Design Optimization

  • Paper of Distinction · IDETC 2026
  • LLM agents
  • FEA–AI hybrid
  • Uncertainty
  • IPMSM

Interior permanent magnet synchronous motor (IPMSM) design requires balancing conflicting objectives and multi-physics constraints, while modern optimization workflows face three bottlenecks: manual problem setup, high finite element analysis (FEA) cost, and unreliable surrogate-based search in sparse or out-of-distribution regions. To address these limitations, we propose an end-to-end automated IPMSM design optimization framework that integrates retrieval-augmented generation (RAG) for structured problem definition with an uncertainty-aware FEA-AI hybrid optimization pipeline.

Research 02

Multi-Agent based Non-parametric Motor Design Optimization

  • Generative design
  • LLM agents
  • Image → STEP
  • IPMSM

Moving beyond a fixed set of design parameters, this work lets agents explore motor shapes directly as images. A design agent sets up the problem from a reference image, objective functions and the design space; a generation agent creates rotor images, filters them with vector embeddings and geometric features, and edits its own prompts through an LLM that analyzes performance transitions; an evaluation agent converts each image to STEP geometry and scores it with the uncertainty-aware FEA–AI hybrid model.

Related publication

  • Han, J., Yang, S., and Kang, N.* (2026). A Multi-Agent System-Based Non-Parametric Image Generation for IPMSM Design Optimization. KSME.

Research 03

Spatio-Temporal Multi-cylinder Flow Prediction

  • CFD surrogate
  • Coordinate-based network
  • Positional encoding

A spatio-temporal coordinate-based neural network predicts time-series flow fields around multi-cylinder arrays. Time values are embedded with sinusoidal positional encoding, giving the network a rich representation of time, and the predicted velocity-magnitude fields are compared with the CFD ground truth at several instants of the unsteady flow.

Related publications

  • Han, J., Kim, S., Kim, S., Yang, S., Cho, B., Song, C., Kang, J., Song, M., and Kang, N.* (2025). Time-Series Flow Field Prediction of Multi-Cylinder using Spatio-Temporal Coordinate-based Neural Network. KSME.

Research 04

Manufacturing-Aware 3D Geometry Post-Processing Framework via Depth Maps for 3-Axis CNC Milling

  • Manufacturability
  • CAD reconstruction
  • 3-axis CNC

A post-processing framework that turns free-form 3D geometry into shapes a 3-axis CNC mill can actually machine, in three steps: (1) project the geometry along the three fixed machining axes and extract binary contour maps; (2) parameterize the 2D outlines with SDF-based contour smoothing, polyline simplification and line–fillet fitting; (3) reconstruct the CAD model with Boolean subtraction and refine its parameters with IoU-based optimization.

Related publication

  • Kim, S., Han, J., Kim, S., Cho, Y., and Kang, N.* (2025). Manufacturing-Aware 3D Geometry Post-Processing Framework via Depth Maps for 3-Axis CNC Milling.

Research 05

Electromagnetic–Vibration Multiphysics Prediction of IPMSM

  • Multi-physics
  • Conditional VAE
  • 2D → 3D transfer learning

A generative surrogate that maps IPMSM design variables to the motor's electromagnetic–vibration response. A conditional variational autoencoder (CVAE) is first trained on a 2D analysis dataset; its encoder and decoder parameters are then transferred to a second stage that learns 3D analysis results, conditioned on the same design variables.
